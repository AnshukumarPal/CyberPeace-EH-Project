# CyberPeace Ethical Hacking Project

This Project is organized by CyberPeace to demonstrate the vulenerabilities or logic flaws found in a application. We are assigned as Penetration tester to review the application security and give a detail report about our finding and it's impact with of test evidence

## Project Title

This Project demonstrates how an internal business application may trust client-side too much.

## Installation

```
git clone https://github.com/AnshukumarPal/CyberPeace-EH-Project.git
cd CyberPeace-EH-Project
pip install -r requirements.txt
```

## Usage

```
python database.py    # this create a database file named nexus.db
python app.py         # to run this project locally
```
